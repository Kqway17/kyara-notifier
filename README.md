# Kyara Notifier

Application Windows pour kyara.games (timers de boosters, auto-ouverture pilotée par le bot, alertes).

## Télécharger

👉 **[Dernière version (installateur .exe)](https://github.com/Kqway17/kyara-notifier/releases/latest)**

Télécharge et lance `KyaraNotifier-Setup-*.exe`. L'app se met à jour toute seule ensuite.

> Accès réservé aux membres disposant d'un *slot* (attribué sur le Discord).
